# 💳 Loan Approval System

A machine learning project for predicting loan approval using supervised classification algorithms.

The project explores the complete machine learning pipeline—from exploratory data analysis and preprocessing to model training and evaluation—using a real-world loan approval dataset.

---

## Features

- Exploratory Data Analysis (EDA)
- Data visualization and feature analysis
- Missing value handling
- One-hot encoding for categorical features
- Feature scaling using StandardScaler
- Comparison of multiple classification algorithms
- Hyperparameter tuning for k-Nearest Neighbours
- Performance evaluation using multiple metrics

---

## Machine Learning Pipeline

1. Data Exploration
2. Data Visualization
3. Missing Value Handling
4. Feature Encoding
5. Feature Scaling
6. Train-Test Split
7. Model Training
8. Model Evaluation

---

## Models Implemented

- k-Nearest Neighbours (kNN)
- Logistic Regression
- Gaussian Naive Bayes

---

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score

---

## Dataset Analysis

The project investigates how different applicant attributes influence loan approval.

Some observations include:

- Approved applicants generally have higher credit scores.
- Loan amount alone is not a strong predictor.
- Applicant income alone is also not a strong distinguishing feature.
- Most numerical features provide complementary information rather than being highly correlated.
